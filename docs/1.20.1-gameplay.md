# Minecraft 1.20.1 gameplay

Verified September 11, 2026 through the existing CurseForge launcher, Java 17 and 4 GB profiles. Fabric Loader 0.19.5 with Fabric API 0.92.12, and Forge 47.4.10, both with Architectury API 9.2.14. Tests used separate QA worlds and background game input.

Both loaders completed the following checks:

- Restock moved eight cobblestone from the chest into an existing stack of 32, leaving the other stack of 16 unchanged.
- Quick Stack returned a split stack to matching chest storage.
- Dump moved unlocked items and left three Alt-click-locked diamonds in the inventory, with an empty cursor.
- The vanilla recipe book filled the crafting grid with four planks taken from nearby storage. Taking the result produced a crafting table.
- Locked diamonds remained protected after saving and reopening the world. Forge used the normal pause-menu Save and Quit action.
- Inventory controls followed the recipe-book panel, Settings opened, and the animated guide opened both automatically and through Settings.
- Tutorial playback, chapter selection and seeking worked. Screenshots covered inventory actions, Controls, and the crafting sequence. The crafting camera was adjusted to keep the recipe-book tabs within the scene.

The Forge controller's direct world-leave command stalled during teardown; normal Minecraft Save and Quit worked. The interrupted test was repeated through the normal menu. This was a controller issue rather than an inventory-transfer failure.

Optional JEI/EMI adapters compile against their 1.20.1 APIs. Dedicated multiplayer, optional backpack integrations and every GUI scale were not exercised in this pass. Existing automated tests cover item matching, transfer counts, storage rules, toolbar geometry and translations.
